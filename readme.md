# DeDelicio 🍽️

A clean and responsive restaurant website built as a beginner-friendly front-end project using **HTML**, **CSS**, and **Bootstrap**.

DeDelicio presents a simple food-ordering experience where visitors can explore the menu, view special deals, learn more about the restaurant, and use basic pages such as login and cart.

> This project was created for learning and practicing front-end web development, responsive layouts, Bootstrap components, and multi-page website structure.

## ✨ Features

- Responsive restaurant landing page
- Navigation across multiple pages
- Food menu and item browsing
- Deals and promotional sections
- Shopping cart page layout
- Login page layout
- About and privacy pages
- Reusable Bootstrap components
- Image-based food and offer sections
- Beginner-friendly HTML and CSS structure

## 📄 Pages

- `index.html` — Home page
- `menu.html` — Restaurant menu
- `cart.html` — Cart page
- `login.html` — Login page
- `about.html` — About the restaurant
- `privacy.html` — Privacy information
- `box.html` — Additional content page

## 🛠️ Built With

- **HTML5** — Page structure and content
- **CSS3** — Styling and custom layouts
- **Bootstrap** — Responsive design and UI components

## 🚀 Getting Started

No installation or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/faizan-2k000/DeDelicio-Bootstrap-Project.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Use the navigation links to explore the website.

For the best development experience, open the folder in a code editor such as [Visual Studio Code](https://code.visualstudio.com/) and use a local live-server extension.
