# DeDelicio 🍽️

A clean and responsive restaurant website built as a beginner-friendly front-end project using **Bootstrap** mainly.

DeDelicio presents a simple food-ordering experience where visitors can explore the menu, view special deals, learn more about the restaurant, and use basic pages such as login and cart.

## 🔗 Live Demo

https://bootstrap-project-dedelicio.netlify.app

## ✨ Features

- Responsive restaurant landing page
- Navigation across multiple pages
- Food menu and item browsing
- Deals and promotional sections
- Shopping cart page layout
- Login page layout
- About and privacy pages
- Reusable Bootstrap components
- Image-based food and offer sections
- Beginner-friendly HTML and CSS structure

## 📄 Pages

- `index.html` — Home page
- `menu.html` — Restaurant menu
- `cart.html` — Cart page
- `login.html` — Login page
- `about.html` — About the restaurant
- `privacy.html` — Privacy information
- `box.html` — Additional content page

## 🛠️ Built With

- **Bootstrap** — Responsive design and UI components
